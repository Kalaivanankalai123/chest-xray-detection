Chest X-ray Disease Detection SystemWelcome to my final-year engineering project! I built this system to tackle the heavy workload in radiology by automating the detection of chest abnormalities from X-ray images. Developed to align with my Anna University curriculum requirements, this platform facilitates a fully digital workflow between patients, doctors, and scan centers.
🎯 What This Project SolvesI wanted to bridge the gap between AI and practical healthcare. When a scan center uploads an X-ray, my system uses a fine-tuned YOLOv11 deep learning model to instantly analyze the image. It successfully detects 14 different chest diseases—including Pneumothorax, Cardiomegaly, and Pulmonary Fibrosis—with a 0.2 confidence threshold, providing annotated bounding boxes for the doctor to review. 
🚀 Key Features & WorkflowI designed this web portal with three distinct user roles to mimic a real-world clinic:  Patients: Can register securely, browse available doctors, book appointments, and eventually download or print their diagnostic reports.  Scan Center (Admin): Manages the upload of patient X-rays and assigns the images to the correct doctor for review.  Doctors: Can log in to view their queue, trigger the AI detection system on the X-rays, prescribe medication, and finalize notes.  Automated Alerts: Once a doctor finalizes a diagnostic report, my application automatically emails the patient their results.  
🛠️ My Tech StackTo build this end-to-end full-stack application, I utilized:  Backend & Web Server: Python 3, Flask, and Jinja2 templates.  AI/ML: Ultralytics (YOLOv11-nano) and OpenCV for computer vision tasks.  Database: MySQL (using mysql-connector-python) to store user credentials, X-ray file paths, and medical records.  Frontend: HTML5, CSS, JavaScript, and Bootstrap 4.  
📋 How to Run My CodeIf you want to test this application on your local machine, follow these steps:  Import the provided 26chestxraybd.sql file into a local MySQL server (like XAMPP or WAMP) using the root user with no password.  Activate a Python virtual environment.  Install my required libraries: pip install flask mysql-connector-python ultralytics opencv-python numpy.  Start the backend server by running python App.py and open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser.
